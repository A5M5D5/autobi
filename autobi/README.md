# AutoBI ERP — نظام إدارة المعارض وتحليلات الأعمال (النسخة المصححة v1.1.0)

نظام مؤسسي متكامل لإدارة معارض السيارات، بطاقات القيد الفني للمركبات، مسار الفرص البيعية (CRM)، التقييم الميداني والاستبدال، الفوترة متعددة العملات، ومؤشرات ذكاء الأعمال (BI) المدعومة بـ Google Gemini AI.

## أبرز الإصلاحات والتحسينات في هذه النسخة (v1.1.0)

1. **إصلاحات الأمان والصلاحيات (Security & RBAC)**:
   - إزالة كلمات المرور النصية المكشوفة من كود الواجهة الأمامية (`LoginPage.tsx`) واستبدالها بمسار تطوير آمن (`/api/auth/demo-login`) يعمل فقط في بيئة التطوير.
   - تشفير كلمات المرور باستخدام خوارزمية `scrypt` المملحة (Salted Hash) مع إنشاء جدول `users` في قاعدة البيانات.
   - تقييد صلاحيات إضافة وتعديل المركبات (`POST /api/vehicles` و `PATCH /api/vehicles/:id`) ومسح الوثائق (`POST /api/gemini/ocr`) على أدوار `Manager` و `Authorized`، وتقييد حذف المركبات (`DELETE /api/vehicles/:id`) على `Manager`.
   - إضافة حماية معززة ضد هجمات CSRF وتحديد معدل الطلبات (Rate Limiting) لمسارات الذكاء الاصطناعي (`/api/gemini/*`) وتنظيف دوري للجلسات لمنع استنزاف الذاكرة.
   - إخفاء رسائل أخطاء قاعدة البيانات الداخلية عن المستخدم النهائي.

2. **إصلاحات الباك إند وقاعدة البيانات (Backend & Database)**:
   - إصلاح ترتيب تحميل `dotenv.config()` في `src/lib/db.ts` و `server.ts` لضمان قراءة إعدادات `.env` بشكل صحيح.
   - توحيد مخطط `database/schema.sql` مع `ensureSchema()` (تعديل `acquisition_channel` إلى `VARCHAR(100)` وإضافة جدول `users`).
   - إيقاف الكتابة القسرية (`localizeOperationalData`) التي كانت تمسح تعديلات المستخدمين عند كل إعادة تشغيل للسيرفر.
   - حساب عمر المركبة في المعرض (`days_on_lot`) ديناميكياً في SQL (`DATEDIFF`) لتعمل تنبيهات الـ 45 والـ 60 يوماً تلقائياً.
   - توليد معرفات السجلات باستخدام `crypto.randomUUID()` لمنع تصادم المفاتيح الأساسية.
   - مزامنة حالات المركبات والصفقات والفواتير تلقائياً عند إصدار الفاتورة أو إغلاق الصفقة.
   - إضافة مسارات إدارة العملاء (`GET /api/customers` و `POST /api/customers`).

3. **إصلاحات الواجهة الأمامية (Frontend & UX)**:
   - إرسال وحفظ كافة حقول الفحص الميداني (`bodyCondition`, `engineCondition`, `interiorCondition`, `tiresCondition`, `mileage`, `supervisorNotes`) في `FieldInspectionApp.tsx`.
   - إضافة نافذة تعديل المركبات وإضافة سجلات الصيانة وحذف المركبات في `InventoryModule.tsx`.
   - إضافة نافذة تسجيل عميل جديد في `SalesPipeline.tsx` وتفعيل فلترة الفرع في الصفقات والفواتير.
   - عزل طباعة الفاتورة عبر `#printable-invoice` في `src/index.css` لمنع ظهور نافذة المساعد الذكي أثناء الطباعة.

## طريقة التشغيل محلياً (XAMPP + Node.js)

1. شغّل خدمة **MySQL** من لوحة تحكم **XAMPP** (سيقوم السيرفر تلقائياً بإنشاء قاعدة البيانات `autobi_db` والجداول والبيانات الأولية عند أول تشغيل، أو يمكنك استيراد `database/schema.sql` يدوياً).
2. انسخ ملف `.env.example` إلى `.env` واضبط `GEMINI_API_KEY` وبيانات قاعدة البيانات عند الحاجة.
3. ثبّت الحزم (إن لم تكن مثبتة):
   ```bash
   npm install
   ```
4. شغّل النظام في وضع التطوير:
   ```bash
   npm run dev
   ```
5. لبناء وتشغيل نسخة الإنتاج:
   ```bash
   npm run build
   npm start
   ```
